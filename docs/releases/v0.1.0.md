# Zeus Tools v0.1.0

Zeus Tools v0.1.0 is the first public Alpha release of the offline developer
toolbox for structured text formatting, inspection, conversion, encoding,
search and hashing.

Zeus Tools v0.1.0 是首个公开 Alpha 版本，是一款用于结构化文本格式化、查看、
转换、编码、搜索和哈希计算的离线开发者工具箱。

## Highlights / 主要更新

- Automatic detection of JSON, XML, YAML, CSV, JWT, Base64 and URL-encoded
  text. / 自动识别 JSON、XML、YAML、CSV、JWT、Base64 和 URL 编码文本。
- Read-only syntax-highlighted result view with normal selection, exact search,
  copying and JSON/XML/YAML folding. / 只读语法高亮结果，支持正常选择、精确
  搜索、复制以及 JSON/XML/YAML 折叠。
- JSON/YAML/XML conversion, CSV table preview and JSON escape/unescape. /
  JSON/YAML/XML 转换、CSV 表格预览及 JSON 转义/反转义。
- One-layer automatic Base64 and URL decoding with explicit continuation. /
  Base64 与 URL 编码自动解码一层，并可手动继续解码。
- Local MD5, SHA-1, SHA-256, SHA-512 and HMAC tools. / 本地 MD5、SHA-1、
  SHA-256、SHA-512 与 HMAC 工具。
- System/light/dark themes, ten interface languages and a localized About
  dialog with open-source acknowledgements. / 跟随系统、亮色与暗色主题、十种
  界面语言，以及包含开源项目致谢的多语言 About 页面。
- Hardened background processing and CSV parsing so malformed input reports a
  concise error instead of terminating the app. / 强化后台处理与 CSV 异常捕获，
  错误输入仅显示简洁提示，不再导致应用退出。

## Downloads / 下载

- `Zeus-Tools-0.1.0-macOS-arm64.dmg`
- `Zeus-Tools-0.1.0-Windows-x86_64-portable.zip`
- SHA-256 checksum files are attached for both artifacts. / 两个产物均附带
  SHA-256 校验文件。

The Windows package is portable: extract it and run `ZeusTools.exe`. No
NSIS/MSI installer is provided. / Windows 为便携版，解压后运行
`ZeusTools.exe`，不提供 NSIS/MSI 安装包。

## Verification / 验证情况

- Core tests: 2/2 passed. / 核心测试：2/2 通过。
- 10 MB JSON and CSV synthetic benchmarks completed. / 10 MB JSON 与 CSV
  合成数据基准测试完成。
- macOS arm64 DMG generated and verified on macOS. / macOS arm64 DMG 已在
  macOS 生成并完成完整性验证。
- Windows x64 executable and Portable ZIP cross-built with MinGW-w64; PE
  architecture, GUI subsystem, VersionInfo, packaged assets and system DLL
  imports were inspected. / Windows x64 EXE 与便携 ZIP 使用 MinGW-w64 交叉
  编译，并检查了 PE 架构、GUI 子系统、版本信息、包内资源及系统 DLL 依赖。

## Known limitations / 已知限制

- Both packages are unsigned. macOS notarization and Windows Authenticode
  signing are not configured. / 两个平台产物均未签名；尚未配置 macOS 公证及
  Windows Authenticode 签名。
- The Windows package has not yet completed native Windows 10/11 startup, IME
  and interaction validation. / Windows 包尚未完成原生 Windows 10/11 启动、
  输入法及交互验证。
- JWT inspection decodes header and payload but does not verify signatures. /
  JWT 查看仅解码 Header 与 Payload，不验证签名。
- YAML intentionally supports a constrained single-document subset. / YAML
  有意只支持受约束的单文档子集。
