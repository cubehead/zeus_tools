# Zeus Tools v0.2.0

Zeus Tools v0.2.0 is the second public Alpha release of the offline developer
toolbox. It expands structured formats and encoding tools, introduces a shared
offline CLI, and substantially improves large-input responsiveness and parser
failure isolation.

Zeus Tools v0.2.0 是第二个公开 Alpha 版本。本次新增多种结构化格式与编码
工具、共用处理注册表的离线 CLI，并重点改善大文本响应速度和异常输入隔离。

## Highlights / 主要更新

- Added TOML and INI/Properties detection, formatting, highlighting, folding
  and JSON conversion. / 新增 TOML、INI/Properties 检测、格式化、高亮、折叠
  与 JSON 转换。
- Added HTML Entity, Hex and Unicode Escape encode/decode plus guarded Unix
  timestamp inspection. / 新增 HTML Entity、Hex、Unicode Escape 编解码及受
  严格条件保护的 Unix 时间查看。
- Added native file open/drop, result export and an offline `zeus-tools-cli`
  pipeline using the desktop processing registry. / 新增原生文件打开/拖放、
  结果导出，以及复用桌面处理注册表的离线命令行管道。
- Added UTF-8-safe paged editing for 1–10 MiB input, bounded long-line drawing,
  virtual CSV presentation and lower peak memory. / 新增面向 1–10 MiB 输入的
  UTF-8 安全分页编辑、超长行受限绘制、CSV 虚拟展示并降低峰值内存。
- Added versioned detection-quality fixtures and execution coverage for every
  registered input and action. / 新增版本化检测质量语料，并实际执行覆盖所有
  注册输入类型和操作。
- Hardened HMAC key cleanup, retained-layer repainting, package validation and
  malformed TOML/CLI failure boundaries. / 加强 HMAC 密钥清理、保留层完整重绘、
  发行包校验，以及畸形 TOML/CLI 异常边界。

- `Zeus-Tools-0.2.0-Windows-x86_64-portable.zip`

## Known limitations / 已知限制

- Both packages are unsigned; macOS notarization and Windows Authenticode are
  not configured. / 两个平台产物均未签名，尚未配置 macOS 公证与 Windows
  Authenticode。
- The Windows package still requires native Windows 10/11 startup, IME and
  interaction validation. / Windows 包仍需在原生 Windows 10/11 完成启动、
  输入法与交互验证。
- YAML intentionally supports a constrained single-document subset. / YAML
  有意只支持受约束的单文档子集。
- JWT inspection decodes header and payload but does not verify signatures. /
  JWT 查看仅解码 Header 与 Payload，不验证签名。
- The paged large-input editor keeps ordinary selection page-local; use its
  dedicated copy action for the complete input. / 分页大文本编辑器的普通选择仍
  限于当前页；复制完整输入请使用专用复制按钮。
