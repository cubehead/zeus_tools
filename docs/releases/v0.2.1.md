# Zeus Tools v0.2.1

Zeus Tools v0.2.1 is a stabilization Alpha release of the offline developer
toolbox. It adds safe Base64 Data URL image previews and binary export, expands
local checksum tools, and hardens Windows input, packaging and runtime behavior.

Zeus Tools v0.2.1 是离线开发者工具箱的稳定化 Alpha 版本。本次新增安全的
Base64 Data URL 图片预览与二进制导出，扩展本地校验工具，并加强 Windows 输入、
打包和运行时稳定性。

## Highlights / 主要更新

- Preview verified PNG/JPEG Base64 Data URLs directly in memory, including
  safe dimensions, searchable summaries and original-byte export. / 对校验
  通过的 PNG/JPEG Base64 Data URL 直接进行内存预览，显示安全尺寸，并保留
  可搜索摘要和原始字节导出。
- Detect common decoded binary formats by magic bytes and export matching file
  extensions instead of rendering binary text. / 根据魔数识别常见二进制格式，
  使用匹配扩展名导出，不把二进制数据显示为乱码。
- Add CRC32, SHA-384 and HMAC-SHA384 with Hex/Base64 output and appropriate
  security guidance. / 新增 CRC32、SHA-384 与 HMAC-SHA384，并提供 Hex/Base64
  输出和相应安全提示。
- Add ASan/UBSan coverage plus a render-layer Data URL image smoke test. /
  新增 ASan/UBSan 覆盖与渲染层 Data URL 图片冒烟测试。
- Improve Windows button sizing, UTF-8 compilation, IME composition handling,
  CNG hashing, portable static runtimes and package validation. / 改善 Windows
  按钮尺寸、UTF-8 编译、IME 预编辑、CNG 哈希、便携静态运行时和包校验。

## Downloads / 下载

- `Zeus-Tools-0.2.1-macOS-arm64.dmg`
- `Zeus-Tools-0.2.1-Windows-x86_64-portable.zip`
- SHA-256 checksum files are attached for both artifacts. / 两个平台产物均附带
  SHA-256 校验文件。

The Windows package is portable: extract it and run `ZeusTools.exe`; the CLI is
`zeus-tools-cli.exe`. No NSIS/MSI installer is provided. / Windows 为便携版，
解压后运行 `ZeusTools.exe`，命令行为 `zeus-tools-cli.exe`；不提供 NSIS/MSI。

## Verification / 验证情况

- macOS application test suite: 5/5 passed; ASan/UBSan core suite: 4/4 passed. /
  macOS 应用测试 5/5 通过；ASan/UBSan 核心测试 4/4 通过。
- Detection regression corpus: 57/57 exact matches. / 自动检测回归语料：
  57/57 精确匹配。
- Exact 10 MiB JSON and CSV benchmarks completed without a material regression. /
  精确 10 MiB JSON/CSV 基准完成，未发现明显性能回退。
- Both final packages passed checksum, metadata, runtime-resource, license and
  forbidden-file validation. / 两个平台最终包均通过校验值、元数据、运行时资源、
  许可证和禁止文件检查。

## Known limitations / 已知限制

- Both packages are unsigned; macOS notarization and Windows Authenticode are
  not configured. / 两个平台产物均未签名，尚未配置 macOS 公证与 Windows
  Authenticode。
- The current Windows package is cross-built; Windows 10 native startup, IME
  and interaction validation remains pending. / 当前 Windows 包为交叉构建，
  Windows 10 原生启动、输入法与交互验证仍待完成。
- YAML intentionally supports a constrained single-document subset. / YAML
  有意只支持受约束的单文档子集。
- JWT inspection decodes header and payload but does not verify signatures. /
  JWT 查看仅解码 Header 与 Payload，不验证签名。
- Paged large-input selection remains page-local; use the dedicated copy action
  for the complete input. / 分页大文本的普通选择仍限于当前页；复制完整输入请使用
  专用复制按钮。
